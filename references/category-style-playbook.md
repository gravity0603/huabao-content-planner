# 华为画报十品类运营与标题风格手册

> 版本：v1.0.0｜日期：2026-09-02
> 依据：`D:\yiyouliao working\选题参考\` 12份 CSV，631个物理数据行、629条非空主标题、52条独立并列标题、583条非空副标题。
> 证据边界：本手册提炼的是参考样本的表达机制，不是效果数据；CTR、曝光和品类优先级以 `knowledge-base.md` 中注明范围的后台数据为准。

## 使用方法

1. 先按共享治理契约完成品类路由和原子候选卡。
2. 只读取目标品类章节，提取对象、钩子、证据和收益槽。
3. 标题负责对象与认知缺口，副标题负责证据与答案方向。
4. 当前用户直接规则、红线和有范围的后台数据优先于历史参考样本；尤其座驾标题继续执行知识库中的“人味口语风”，不得退回指南腔。

## 1. 动物萌宠

- **定位**：猫狗为主、熊猫偶见；先让用户看到动作、表情、姿势或成长反差，再交付行为知识或陪伴共鸣。
- **高适配母题**：翻车抓拍、高冷与笨拙、迎接陪伴、可见行为知识、成长/造型对比。
- **标题**：≤7字；`猫/狗+异常动作？`、`行为+疑问`、`对象+拟人状态`。拟人只是翻译，不是医学诊断。
- **副标题**：一个动作证据 + 一个解释/笑点/情绪收益；使用“像、可能、仿佛”保护确定性。
- **不做**：泛动物挤占萌宠；“抑郁、致死、保命”等无证据结论；靠“最后一张”支撑的空合集。
- **口诀**：先看动作，再翻译情绪。

## 2. 插画呈现

- **定位**：插画是呈现标签，不是兜底内容品类；核心价值必须来自步骤、关系、对照、谜面、时间线或情绪隐喻。
- **高适配母题**：亲子沟通、心理认知、历史生活、视觉谜题、睡眠安全、学习方法、童年怀旧。
- **标题**：≤10字；`痛点+怎么办？`、`别+错误动作`、`古人也会+现代问题？`、`数字+方法`、`视觉谜面+挑战`。
- **副标题**：把抽象问题变成数量、步骤、场景或第一层线索；互动题给线索不泄底。
- **不做**：恐吓育儿、模糊专家背书、相关性写成因果、数字与正文不对应、没有视觉机制的普通文章。
- **口诀**：先定信息结构，再决定怎么画。

## 3. 动漫

- **定位**：熟悉 IP 负责开门，陌生细节负责交付；以粉丝身份确认、童年记忆、二刷细节和设定谈资为主要收益。
- **高适配母题**：角色成长、彩蛋设定、经典 IP 变化、配角/反派、配音制作、作品价值。
- **标题**：≤10字，优先7—9字；`角色/IP+隐藏信息`、`细节+疑问`、`角色判断`、`时间跨度+经典对象`。
- **副标题**：尽早补作品名，点一个镜头、配音、设定或角色选择；资讯给核验时间，解读标个人观点。
- **不做**：粉丝猜测冒充官方设定、关键剧透、只用“封神”代替理由、副标题堆角色名、新作信息不核时效。
- **口诀**：熟悉 IP 开门，陌生细节交付。

## 4. 旅行风光

- **定位**：不是泛泛说美，而是具体哪里违反常识、能一眼成像、值得转述。
- **高适配母题**：高画面的颜色/形状/尺度，高谈资的地名/规则/生活方式，高反常的预期与现实冲突。
- **标题**：≤7字；`对象+反常动作？`、`地点/对象+视觉隐喻`、`熟悉对象+隐藏规则？`。
- **副标题**：地点/对象事实 + 一个尺度、机制或构图兑现；诗性标题字面化，问句给答案方向。
- **不做**：“绝美地方、神秘景点、超现实照片”等泛对象；用“惊现、震撼”伪造反常；首图无法证明。
- **口诀**：一眼成像，一个反常。

## 5. 明星

- **定位**：群像是常青主力；单人依赖近期、公开、积极、可视的职业事件。安全反差来自职业能力、公开训练和角色塑造，不来自隐私或身体评价。
- **高适配母题**：可见造型特征、学校/专业/旧职业、声线/舞蹈/运动/创作、同学搭档、节目反差、角色—演员比较。
- **标题**：优先6—8字、≤10字；群像用`人物类别+一个可见特征/经历`，单人用`姓名+具体职业动作/公开事件`。
- **副标题**：群像用`N位+共同特征+1—2个代表差异`且最多点2名；单人用`人物动作+过程/专业价值`，不重复标题身份。
- **不做**：绯闻、婚变、未成年子女、健康、整容、身材羞辱、未经证实关系、非必要国籍民族信息；未完成近期负面舆情检索不得上架。
- **口诀**：群像看同点，单人看动作。

## 6. 影视

- **定位**：必须落到作品、角色、场景、道具、镜头或明确观影场景；演员经历与外形转明星类。
- **高适配母题**：道具/动作/画幅/台词伏笔、角色动机、同类场景、形式创新、亲子片单、幕后制作与文化元素。
- **标题**：≤10字，优先7—9字；`角色为何+动作？`、`物件+反常作用`、`场景+情绪结果`、`观看场景+看什么？`。
- **副标题**：`《作品》+具体证据+答案方向/观看收益`；个人解读使用“可理解为、可能”。
- **不做**：关键剧透、个人解读当定论、无来源高分/票房/必看、演员绯闻伪装影视内容、只有海报无镜头。
- **口诀**：从具体镜头进，不从空泛情绪进。

## 7. 科技

- **定位**：把抽象知识翻译成异常画面、人类处境或生活类比；航天只是样本高频方向，不等于科技全部。
- **高适配母题**：观测纪录、反常现象、技术机制、思想实验、研究推测、极端环境；主动补 AI、机器人、材料、能源和工程。
- **标题**：≤10字，适合8—10字；`对象+反常现象？`、`纪录+事件`、`对象+拟人身份`、`人类处境+极端环境？`。
- **副标题**：观测事实/一个关键数字 + 机制或纪录意义；明确已确认、推测、假设。
- **不做**：把可能写成证实、用机构名作装饰、无答案的外星人/超光速伪命题、惊吓词堆砌。
- **口诀**：类比负责好懂，证据负责准确。

## 8. 座驾/交通

- **定位**：覆盖汽车、飞机、船舶等交通工具；兼顾视觉奇观与生活机制/安全知识。标题表达以知识库最新“人味口语风”规则为准。
- **高适配母题**：速度/尺寸/存量、局部结构、制动/抓地/转弯机制、交通标识与安全、技术演变、日常出行痛点。
- **标题**：≤10字；题眼可来自`部件为什么这样`、`巨物如何完成动作`、`日常动作的反常后果`，但最终改写成自然口语、具体比喻或场景反转，禁止“XX指南/攻略/小技巧”式标题。
- **副标题**：参数/部件 + 机制 + 使用或安全收益；极限数字必须带条件、时间和范围。
- **不做**：品牌、价格、升值暗示、无条件“全球最快/唯一”、省油维修偏方、昵称变相软广。
- **口诀**：参数要有条件，知识要能保用。

## 9. 体育

- **定位**：强题来自动作、规则、器材、起源和训练细节；单题只提供看爽、学会、避险或懂规则中的一个主收益。
- **高适配母题**：器材误解、起源反差、新手纠错、装备安全、规则差异、动作名场面、赛事节点。
- **标题**：≤10字，优先7—9字；`器材/项目+常识纠偏`、`规则差异+为什么？`、`动作+视觉比喻`、`项目+起源反差`。
- **副标题**：动作/条件 + 机制、技巧或规则答案；健康功效写明研究人群、条件和来源。
- **不做**：无边界长高/延寿/减重承诺、阶层焦虑、高风险运动只讲刺激、人物和赛事不核时间。
- **口诀**：动作可见，规则可答，功效有边界。

## 10. 艺术

- **定位**：具体作品、器物、纹样、传统技艺和博物馆细节；现代口语开门，专业细节收口，让用户看懂一个细节。
- **高适配母题**：名画构图/表情、文物造型/纹样/材质、开片/烧制等工艺、艺术人物反差、博物馆幽默、器物用途。
- **标题**：≤10字，优先7—9字；`器物/名作+异常细节？`、`历史人物+现代动作？`、`工艺动作+反常结果？`。
- **副标题**：作品/器物身份 + 一个可见细节 + 工艺或文化含义；专业信息只保留与题眼相关的一处。
- **不做**：健康财富等杂项混入、用“神级”替代细节、热梗歪曲作品、只有档案式说明无题眼。
- **口诀**：用现代话开门，用专业细节收口。

## 批量多样性

- 同一批次避免同一问句开头、同一热词、同一引号拟物或同一主钩子连续出现；这是表达多样性检查，不能替代 H/R/B 概念去重。
- 盘点必须有可感知的筛选标准；不能以“明星盘点、旅行美图、萌宠合集”充当题眼。
- 每条都能回答：对象是什么、唯一钩子是什么、首图哪里证明、用户看完得到什么。任一答不出，先退回候选卡。
