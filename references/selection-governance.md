# 华为画报选题治理契约

> 版本：v1.1.0
> 生效日期：2026-09-02
> 适用：华为画报通用、明星、旅行、周报及标题优化 Skill

本契约统一解决：输入口径、品类路由、事实确定性、月报参考风格、H/R/B 跨会话去重、画面兑现、标题—副标题分工、硬门槛与质量评分。它不替代各品类红线、来源核验、图片审核和 P/月报业务评分。

参考表只能证明“历史样本如何写”，不能证明“哪种写法一定带来更高流量”。涉及效果的判断必须另接后台数据，并标明数据范围与观察期。

## 1. 输入优先级与时间口径

每次任务先分别确定三个时间字段，禁止混写：

| 字段 | 用途 | 优先级 |
|---|---|---|
| 素材范围 | 检索/筛选原文的发布时间范围 | 用户当次范围 > 目标上线日/栏目期次 > Skill 默认 > 常青或季节素材 |
| 目标上线日 | 判断“近期已出”的相对基准 | 用户指定 > 当天 |
| 去重窗口 | 比对近期已上传内容 | 自目标上线日向前至少30个自然日；用户要求更长时扩展 |

- 用户说“近45天”“7月”“截至某日”“不限制时间”时，必须覆盖 Skill 默认时效。
- 常青或季节内容可超出素材范围，但要标明仍适合本次的事实理由。
- 「一周情报站」默认检索近7天，但用户明确范围优先；去重窗口仍至少30天。

## 2. 先路由，再生成

看内容的**核心对象与用户最终收益**，不要只看素材来源或呈现形式：

| 核心对象/问题 | 路由 |
|---|---|
| 猫狗行为、养宠关系；熊猫偶见 | 动物萌宠 |
| 图解、步骤、谜题、对照或情绪可视化 | 内容归实际主题，另标 `format: illustration` |
| 动画作品、角色、设定、镜头或制作 | 动漫 |
| 地点、景观、建筑、地理现象或旅行生活 | 旅行风光 |
| 艺人的公开职业、造型、经历、技能或群像 | 明星 |
| 影视作品、角色、剧情、道具、镜头或观影收益 | 影视 |
| 科学观测、研究发现、技术机制或工程原理 | 科技 |
| 汽车、飞机、船舶等交通工具、部件、驾驶/航行规则 | 座驾/交通 |
| 运动项目、动作、规则、器材、训练或赛事人物 | 体育 |
| 作品、器物、纹样、传统工艺、艺术人物或审美细节 | 艺术 |

冲突时：演员经历归明星，角色动机归影视；古桥景观归旅行，工艺审美归艺术；飞机结构归座驾/交通，航天器入轨归科技；真实猫狗归萌宠，动物角色归动漫。插画不是兜底品类。

## 3. 强制原子候选卡

新选题在写标题前，先内部建立下列卡片；标题优化任务必须锁定其中已有字段，不能擅自补写：

```yaml
category: 目标品类
format: photo/illustration/video-frame/mixed
object: 可被一眼识别的具体对象
fact_core: 一句话可核事实
source:
  url: https://...
  level: 官方/权威媒体/专业机构/可靠二手/待验证
  date: YYYY-MM-DD
  verified: true/false
certainty: 已确认/研究推测/理论假设/个人解读/待验证
visual_anchor:
  cover: 首图具体看到什么，以及哪处证明题眼
  body:
    - 内页画面1
    - 内页画面2
    - 内页画面3
user_value: 笑点/知识/审美/实用/谈资/共鸣（选主值）
hook_type: 视觉反常/机制揭秘/身份信息差/实用决策/情绪共鸣
hook_sentence: 唯一题眼
risk_flags: 舆情/健康/安全/品牌/隐私/版权/剧透/时效/敏感身份
hrb_status:
  H: 通过/命中/未完成
  R: 通过/命中/覆盖不足/解析待核
  B: 通过/命中/未完成
```

关键字段为空时按事实降级：无对象不写泛标题；无核心事实不以悬念掩盖；无直接来源只进待验证池；首图不能证明题眼则换图、换切口或淘汰；内页不足3种不同画面不得进入正式候选；无 H/R/B 不得声称已去重。

## 4. 月报参考表与风格指纹

### 4.1 语料来源

默认读取 `D:\yiyouliao working\选题参考\` 中对应品类 CSV：

- 旅行：`旅行类标题参考.csv` + `旅行风光.csv`
- 明星：`明星类标题参考.csv` + `明星.csv`
- 其他品类：对应月度 CSV；跨品类样本只能辅助

月度表月份常只写在连续区块第一行，需要向下继承；无法确认排序或月份时标低置信度。参考表先过滤重复、旧规则冲突、品类污染、错配副标题和无法核验的绝对化措辞。旅行参考表第三列是独立标题池，不得和同一行副标题配对。

### 4.2 风格指纹

每条候选内部生成：

```text
品类 | 对象锚点 | 单一钩子 | 标题结构 | 副标题兑现方式
```

品类细则读取 `category-style-playbook.md`。参考表只提供对象槽、钩子槽、证据槽和收益槽，不提供可直接复用的题目、事实、名单或结论。若参考风格与已验证的用户直接规则或后台数据策略冲突，以更具体、更新、证据更强的规则为准，并说明取舍。

## 5. H/R/B 跨会话概念去重

### 5.1 三层比对集

| 集合 | 默认来源 | 作用 |
|---|---|---|
| H（History） | `D:\yiyouliao working\工作内容\每周数据\数据库\zcy华为画报选题-张朝阳已做.csv` | 全历史已做主题；日期不完整也参与 |
| R（Recent） | `D:\yiyouliao working\工作内容\每周数据\数据库\互联网日报表（<目标上线年份>年）-华为上传图组标题.csv`；若当年文件不存在，再读取用户当前指定的最新上传表 | 目标日前至少30天近期上传主题 |
| B（Batch） | 当前批次、当前对话已产出与已否决候选 | 防同批、同会话重复 |

H 日期不完整时不得用它精确筛近期，但仍作为全历史强比对集。R 的`图组名称`按中文顿号拆分；拆分数量异常时，同时比对原字符串与可拆标题并标“解析待核”。R 必须能证明连续覆盖整个去重窗口：覆盖起点不得晚于窗口起点，覆盖终点须达到目标上线日；若目标日尚未到达，则至少达到本次明确记录的数据截止日。起点、终点或连续性任一无法确认，统一标`R 覆盖不足`，不得宣称近期去重通过。

### 5.2 概念指纹

```text
品类 | 主体对象 | 核心事实 | 视觉题眼 | 用户收益 | 叙事角度
```

标题结构只属于风格指纹，不能作为“新题”证据。标题相同、主体与事实相同、画面与叙事同构，或同一概念族拟第三次使用，均视为重复；不能靠换词、换地点名或换问句规避。

### 5.3 去重回执

```text
去重回执：H 通过/命中；R 通过/覆盖不足/解析待核；B 通过/命中。
窗口：YYYY-MM-DD–YYYY-MM-DD；R 数据覆盖：YYYY-MM-DD–YYYY-MM-DD；数据截止日：YYYY-MM-DD；H 最近数据：YYYY-MM-DD/日期不完整。
```

仅 H/R/B 均通过且 R 覆盖目标窗口时，才能标“可上架”或“主推”。标题优化没有有效上游回执时只能标：`文字优化草案，不可直接上架。`

## 6. 标题、副标题与落地页

### 6.1 先选一个钩子

五种钩子只能选一个主钩子：视觉反常、机制揭秘、身份信息差、实用决策、情绪共鸣。其他信息只能作为证据或拆成另一题，不得把第二个卖点塞进副标题。

### 6.2 三结构比较

先根据同一事实工作稿各写一个**陈述型、疑问型、隐喻/画面翻译型**版本，再选最贴合事实和品类的一版；三版必须改变信息组织方式，不能只换同义词。某结构与事实不相容时写“该结构不适用”并说明原因，不得硬造问句或比喻。

标题先过五项，再计字数：

1. 对象明确；
2. 只有一个新鲜钩子；
3. 承诺可由来源、首图、副标题和落地页兑现；
4. 品类与参考语气匹配；
5. 朗读自然完整。

通用标题≤10字，旅行/萌宠≤7字，副标题≤25字；疑问句用中文 `？`。压缩只能删重复修饰、空泛情绪词或无信息连接词，不能删除事实主语、关键动词、必要条件或确定性限定。

### 6.3 标题—副标题分工

- 标题：对象 + 单一认知缺口。
- 副标题：具体证据/场景 + 机制、差异或用户收益；最多两层信息。
- 疑问标题的副标题必须给出答案方向。
- 标题与副标题不得换词复述；副标题不能新增第二钩子。
- 落地页必须维持与标题相同的事实范围和确定性，不得在正文中升级结论。

标题优化固定流程：锁定事实、对象、画面、确定性和收益 → 诊断原题 → 三结构比较 → 唯一推荐并说明取舍。若没有具体对象、可核事实、可见题眼或阅读收益，返回 `应换题`，不靠文案硬救。

## 7. 事实确定性与措辞

| 状态 | 可用措辞 | 禁止措辞 |
|---|---|---|
| 已确认事实 | 已发现、已观测、数据显示（带范围） | 无范围的“全球唯一、永远、全部” |
| 研究推测 | 可能、研究推测、或与……有关 | 证实、明确、真相就是 |
| 理论假设 | 假如、理论上、模型显示 | 现实中已经、科学家发现 |
| 个人解读 | 可理解为、像是、可能暗示 | 官方设定、导演明确表达 |
| 待验证 | 待核实、暂不出题 | 任何确定性标题 |

数字、排名、首次、唯一、纪录、功效必须有范围、条件、时间和直接来源。来源只支持背景而不支持题眼时，仍视为核心事实未核验。

## 8. 最终候选硬门槛

任一项失败即淘汰、退回或降级；高分不能抵消：

1. 标题超限；
2. 副标题超限；
3. 疑问句缺中文问号；
4. 无实际打开的直接 `https://` 来源；
5. 标题与来源事实或确定性不一致；
6. 标题与副标题错配、复述或双钩；
7. 首图不能证明题眼，或正式候选不足3种内页画面；
8. H/R/B 未完成、命中重复或 R 覆盖不足；
9. 人物近期负面舆情未排除；
10. 健康、安全、科学确定性被夸大；
11. 品牌软广、价格刺激、投资暗示未消除；
12. 隐私、版权、关键剧透或敏感身份风险未处理。

纯标题改写可在信息不全时产出草案，但必须列明缺口，且不得使用正式候选状态和总分。

## 9. 100分质量评分与业务评分

硬门槛通过后再评分：

| 维度 | 分值 | 满分标准 |
|---|---:|---|
| 事实与来源 | 20 | 直接来源、事实准确、确定性一致 |
| 画面兑现 | 15 | 首图可证，内页至少3种不同画面 |
| 新颖与去重 | 15 | H/R/B无冲突，不是旧题换词 |
| 单一钩子 | 10 | 一题一钩，证据不抢钩子 |
| 品类适配 | 10 | 对象、收益、表达符合品类 |
| 标题清晰 | 10 | 具体自然，字数与标点合规 |
| 副标题兑现 | 10 | 有新信息，回答标题，最多两层 |
| 用户收益 | 5 | 笑点/知识/审美/实用/谈资/共鸣明确 |
| 语言自然 | 3 | 无机械压字，朗读顺畅 |
| 风险控制 | 2 | 风险已识别并处理 |

阈值：85—100 为主推质量；75—84 可用；65—74 修改后复审；低于65淘汰。

100分评估内容完整度与表达质量，不替代 P 潜力 A/10、月报潜力 B/10 等业务评分。专项仍使用 A/B 时：主推必须同时满足硬门槛、总分≥85、A≥7、B≥8；A/B 不足时按专项规则降级。没有完整候选卡时不报总分。

## 10. 最小输出回执

新选题最终输出至少包含：品类、状态、素材范围/目标上线日/去重窗口、核心事实、来源等级与日期、确定性、首图和3种内页、主钩子、用户收益、风格指纹、概念指纹、H/R/B 回执、R覆盖起止与数据截止日、标题/副标题/落地页、100分与弱项、专项业务分、风险结果。

状态统一使用：`待验证`、`待补画面`、`待排舆情`、`去重未完成`、`修改后复审`、`可用`、`主推`、`应换题`、`淘汰`。不得用模糊的“应该可以”“基本没问题”代替失败原因。
